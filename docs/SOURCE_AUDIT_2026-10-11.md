# YAuto 全仓源码审计与集中修复（2026-10-11）

基准：用户上传的 1,477 个文件（其中 642 个 Kotlin 源文件）；目标分支 `refactor/macrodroid-on-1003-20261008`。本报告记录源码及回归测试，不等同于 OxygenOS 全功能真机验收。

## 本批已修复

- **Hook 会话令牌**：相同 sessionId 的不同令牌不再被本地覆盖；重装失败只回滚本次新增的匹配令牌，保留已工作的旧会话。
- **Hook 请求校验**：拒绝无效 sessionId 和短/空的事件令牌，防止错误凭据进入运行时。
- **跨进程请求**：捕获 Android 有序广播提交的异常，设置/诊断/按键捕获不再因此直接崩溃。
- **LSPosed 事件回调**：系统事件和方法 Hook 回调异常隔离；分别记录接收、转发、拒绝及运行时处理失败。
- **诊断误报**：单次历史拒绝不再永久标红，仅在主动认证往返失败或最近五分钟发生错误时给出警告；计数保留。
- **高频日志**：限制重复回调错误日志速率，避免日志洪泛，且不输出会话令牌或事件私密内容。
- **无障碍回调**：窗口、按键、UI、指纹事件监听器的异常不再直接逃逸到系统服务生命周期。
- **等待界面空闲**：超时和安静窗口相互独立，用户设置的超时不会被强制延长。
- **权限状态**：Shizuku 授权独立核实；Root 仍可以作为功能执行的优先后端，但不再伪造 Shizuku 未授权状态。
- **CI**：移除已删除的 test 分支过滤，加入无障碍空闲/回调保护回归检查。

## 本地审计结果

137 项 Python 自动回归测试通过；多语言、启动安全、事件契约、架构、权限接线、FeaturePack Schema、MacroDroid 分类与重复项目审计通过。启动安全核对 520 个字面量和 172 个展开的 FeatureDescriptor ID，检测到的兼容别名无冲突。原生 Kotlin 编译和 Debug APK 以本提交 GitHub Actions 结果为准。

## 下一批：窗口、AppOps 与实体按键可靠性

- **窗口状态识别**：Accessibility 内容更新不再覆盖窗口 Activity 类名；不同包名的真实切换仍保留。
- **AppOps 重复 Hook**：同一 ROM 同时存在公开方法和 Impl 方法时优先公开方法，缺失时回退 Impl；相同 UID/包名/操作码/阶段采用 75ms 去重，开始与结束事件永不互相合并。
- **实体按键捕获**：忽略 KEYCODE_UNKNOWN 与异常 action，不再提前消费用户等待中的合法 Android KeyEvent。
- **回归约束**：新增 JVM 与静态契约测试；真实 ROM 的方法签名与事件时序仍需手机验证。

## 未声称解决的边界

- 系统服务器 AppOps、窗口生命周期、SystemUI 和厂商 Hook 的方法签名需要 OxygenOS 真机逐项验证。
- ShortX 来源清单包含 193 个动作类型；97 项有解析分支、95 项只具提示语义；并不代表全部具备原生完整执行能力。
- 基于 UsageStats 的“最近应用”动作不等同于 ShortX 真正的系统任务栈导航。
- ShortX 插件 ActionEvaluator/ParamsData 与未知 Any 数据结构、特定厂商扩展仍未达到完整等价。
- 已连接 LSPosed、已安装 Hook 或通过 CI，都不足以证明某个触发器已在具体设备上执行；应以事件认证往返、运行时回调和真机结果共同确认。
